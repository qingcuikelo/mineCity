# MineCity — 复古等距城市建造沙盒

一个**完全离线预渲染**的网页版等距城市沙盒：没有 Blender、没有实时 PBR。
所有建筑、地形、道路、道具都由 `tools/` 里的**自研 Node 离线渲染管线**用代码程序化建模，
以固定 2:1 等距正交视角批量光栅化为透明背景精灵图，再经 32 色 PC98/DOS 风格调色板 +
有序抖动（Bayer 4×4）+ 扫描线 / RGB 亚像素偏移 / 磷光辉光 / 晕影 CRT 后处理呈现。
运行时网页只做精灵合成，不进行任何 3D 计算。

```
┌─ 离线（构建期，Node，零依赖）───────────────┐   ┌─ 运行时（浏览器，原生 ESM + Canvas2D）──┐
│ 代码建模 → z-buffer 软件光栅化 → 光照       │   │ 读 manifest 图集 → 等距画家排序合成      │
│ → 32 色量化 + 有序抖动 → 精灵图集 + 清单     │ → │ → DOS 风格 UI → CRT 后处理                │
└────────────────────────────────────────────┘   └──────────────────────────────────────────┘
```

## 快速开始

```bash
npm run build     # 离线渲染全部精灵（约 2 秒，产出 assets/）
npm run verify    # 校验图集：每个不透明像素必须 ∈ 32 色板
npm run dev       # 启动零依赖静态服务器
# 浏览器打开 http://localhost:8123/
```

产物 `assets/` 已随仓库提供，理论上 `npm run dev` 即可直接游玩；`npm run build` 用于重新生成。

> 若要修改 UI 用到的汉字（点阵字库）：先 `npm run charset`（自动扫描 `src/` 用到的字符并
> 同步进烘焙页），再打开 `http://localhost:8123/tools/font-bakery.html` 点 Bake ——
> 页面用系统宋体渲染 ASCII + 汉字 + 符号，并 POST 回开发服务器写入 `assets/font-glyphs.json`。

## 玩法（无复杂经营）

| 工具组 | 说明 |
|---|---|
| 地形 | 抬升 / 降低 / 整平 / 草地 / 沙地 / 岩石 / 泥地，可调 1×1、3×3、5×5 笔刷 |
| 自然 | 挖水面、种森林、灌木、石块 |
| 道路 | 拖拽修路，16 方向自动拼接（人行道 / 斑马线 / 井盖随 mask 生成）|
| 分区 | 拖拽划定住宅 / 商业 / 工业；**邻路分区地块会自动生长建筑**，并在邻接开发密度提高后升级（工地 → 建筑 → 更高档） |
| 地标 | 市政厅 / 教堂 / 学校 / 公园 / 广场，点击放置，R 键旋转 |
| 系统 | 新建（种子 / 水位 / 起伏）、**一键城镇**、4 槽位存档读档、帮助、网格、CRT 开关、自动昼夜 |

**一键城镇**：点一下「系统 → 一键城镇」，程序会自动寻找一块空旷平地（找不到会提示），
整平地形、铺出 4×4 街区的路网、按街区位置分配住宅/商业/工业、放上公园/广场/市政厅/教堂/学校，
运行若干模拟步让建筑长出来，并把镜头对准新镇。街区内部留作庭院绿化（种树/灌木/石块），
因此不会再出现永远无法临路的空地；连点可在别处继续造镇（`src/game/town.js`）。

- **操作**：左键使用工具；右键 / 空格拖拽平移；滚轮 1x/2x 缩放；`1`–`6` 切换工具组；
  `[` `]` 调整时间；空格暂停；`G` 网格；`R` 旋转地标；`F` 浏览器全屏；`n/k/l/h` 打开新建 / 存档 / 读取 / 帮助。
- **显示**：像素缩放始终取整数倍（不模糊），逻辑分辨率随窗口自适应扩大以**铺满窗口**——
  窗口越大看到的地图范围越大（例如 1920×1080 → 952×532 逻辑像素 @2x）。
  最小基准 640×400（PC98 味），高度不足 400 的小窗口会退化为 1x 局部显示。
- **昼夜**：状态栏右侧有手动时间滑块，夜版精灵亮窗 + 路灯辉光 + 水域变暗，建筑昼/夜交叉淡入。
- **存档**：localStorage 4 槽位（含日期、人口摘要），`src/game/save.js` 亦提供 JSON 导入导出函数。

## 技术要点

- **零依赖**：Node 侧自写 PNG 编码器（zlib + CRC32）与软件光栅器；浏览器侧无框架、无构建步骤。
- **光栅器**：正交 2:1 投影（`sx=(X−Y)/2, sy=(X+Y)/4−Z`），逐像素 z-buffer，
  面法线平面光照仅 4 档亮度（顶面 1.0 / +Y 0.87 / +X 0.67 / 背光 0.32），
  材质是带程序化纹理的纯函数（砖纹、窗格、招牌、水面波纹、屋顶棱线）。
- **量化**：每个像素先取最近调色板项定位色阶 ramp，再按亮度在 ramp 上做 Bayer 抖动，
  因此平面与斜面自然出现 PC98 式抖动过渡；描边/标线可用 `crisp` 关闭抖动。
- **昼/夜**：同模型渲染两遍，夜间建材压暗、窗户按哈希点亮（自发光色），
  精灵图集同时存放 day/night 两版，运行时按时间因子交叉淡入。
- **排序**：所有绘制按对角线 `x+y` 升序，同对角线先地形后物体、物体内按 `y` 升序；
  多格建筑绘制在其“最前排”对角线，避免大底面精灵穿插伪影。
- **键位提示**：`docs/pipeline.md` 记录了如何新增建筑模型与重新烘焙。
